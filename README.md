# Embedded Systems Portfolio

A collection of embedded systems projects across several microcontroller platforms, built as part of my training in mechatronics engineering. The goal is to document hands-on work in firmware development, peripheral drivers, and real-time systems.

> **Project status:** early stage. The repository structure is defined and the **STM32** work is in progress. No source code has been published yet; the other platforms are planned.

## Conventions

Each project is intended to include:

- A short README with its goal, hardware used, and wiring or pin mapping
- Build and flash instructions
- Source code organized by module (drivers, application logic)
