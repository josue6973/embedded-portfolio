# Embedded Systems Portfolio

This repository contains firmware and documentation for my embedded systems projects. Each project is organized by platform and includes source code, wiring diagrams, build instructions, and test results.

The goal is to demonstrate practical experience with microcontrollers, peripheral drivers, communication protocols, and real-time firmware design.

## 🧰 Supported Platforms

| Platform | MCU / Board | Toolchain | Status |
|---|---|---|---|
| STM32 | Nucleo L476RG (Cortex-M4) | STM32CubeIDE | Active |
| ESP32 | DevKit V1 | Arduino IDE / ESP-IDF | Active |
| Arduino | Uno (ATmega328P) | Arduino IDE | Active |
| PIC | PIC16F877A | MPLAB X + XC8 | Active |

## 📁 Repository Structure

- Master STM32 HAL and low-level register programming
- Implement FreeRTOS on STM32 and ESP32
